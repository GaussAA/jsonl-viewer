# 实机验收清单（v1.8.0 编辑能力全集）

> 沙箱内只能跑单测与浏览器 harness 模拟，**provider 运行时行为必须实机验证**。
> 安装方式见 `RELEASE.md` §3（`code --install-extension releases/jsonl-viewer-1.8.0.vsix`）。
> 每项给出「操作 → 预期」；全部通过即可打包发布，未通过项请记录现象与文件特征回馈给臣。

## 准备

- [ ] 用扩展打开一个 **大 JSONL**（建议 ≥ 100MB，含对象行、数组行、坏行、超长行各若干）
- [ ] 准备一个小 JSONL（几十行）专门验编辑（改坏了随时重建）
- [ ] 样例 `samples/` 目录下有现成文件可复用

## 1. 只读基线（回归）

| # | 操作 | 预期 |
|---|---|---|
| 1.1 | 打开大文件 | 秒级出首屏；状态行显示总行数与「已解析」渐进增长 |
| 1.2 | 快速滚动到中部/尾部 | 无空白闪现；翻页式目录的范围文本跟随 |
| 1.3 | 点任意记录 | 右侧详情树展开顶层；点字段跳面包屑 |
| 1.4 | 搜索 / 过滤 | 命中计数正确；截断时有如实提示 |

## 2. 单行编辑

| # | 操作 | 预期 |
|---|---|---|
| 2.1 | 选一行 → 工具栏铅笔 | 浮层初始文本 = **磁盘原文**（含原有缩进/键序），不是重新序列化的 |
| 2.2 | 等长改动（改个字母）保存 | 状态行显示「原位覆写」类提示（若实现）；文件 mtime 变化 |
| 2.3 | 变长改动（加长文本）保存 | 保存成功；该行之后的内容完好（滚动抽查几行） |
| 2.4 | 删成非法 JSON 保存 | **拒绝**并说明原因，浮层保持打开 |
| 2.5 | 改完立刻再改同一行 | 第二次的初始文本是第一次改后的内容（基线已同步） |
| 2.6 | 编辑后按 Ctrl+Z | 撤销生效；详情树与列表同步回退 |

## 3. 插入 / 删除

| # | 操作 | 预期 |
|---|---|---|
| 3.1 | 右键「在第 N 行前插入」→ 保存 | 新行出现，后续行号整体 +1；详情树跟随 |
| 3.2 | 右键「删除第 N 行」→ 确认 | 行消失，后续行号 -1 |
| 3.3 | **回归**：插入到第 1 行 → 删除几行 → Ctrl+Z 一路撤到底 | 每一步内容正确（这是修复过的锚点平移缺陷的触发路径） |

## 4. 查找替换（整行文本）

| # | 操作 | 预期 |
|---|---|---|
| 4.1 | 工具栏搜索 → 展开替换 → 全部替换 | 先弹**二次确认**横幅（含重写整文件的代价说明） |
| 4.2 | 确认后 | 横幅走百分比进度（可取消）；结果如实报替换数 |
| 4.3 | 替换会把某行改非法的用例 | 该行被**跳过**且结果里如实报跳过数 |
| 4.4 | 进度中点「取消」 | 显示「已取消：文件未被修改」；文件确实未变 |
| 4.5 | 替换后 Ctrl+Z | 整批一次撤销（不是逐行） |

## 5. 多选批量

| # | 操作 | 预期 |
|---|---|---|
| 5.1 | Ctrl 点多行 / Shift 点范围 | 浮动操作条出现（复制/删除/取消） |
| 5.2 | 批量删除 5000+ 行 | 超上限时拒绝并说明；未超限时一次原子重写 |
| 5.3 | 批量删除后 Ctrl+Z | 一次撤回全部 |

## 6. 会话编辑历史

| # | 操作 | 预期 |
|---|---|---|
| 6.1 | 工具栏「历史」 | 浮层列出本次会话全部写操作（最新在上；已撤销的置灰加删除线） |
| 6.2 | 点中间某条「停在这一步」 | 文件回退到那一步，其后条目置灰 |
| 6.3 | 点置灰条目 | 文案变「重做」，点击即重做 |
| 6.4 | **关键**：把 2/3/4/5 各做一遍，然后「五种操作混合后一路撤销到底 / 重做到底」 | 两端点的文件内容与最初**逐字节一致**（长链不变式，这是历史系统最重要的验收） |

## 7. 坏行诊断

| # | 操作 | 预期 |
|---|---|---|
| 7.1 | 打开含坏行的文件后什么都不做 | 状态行出现「⚠ N+ 坏行」徽章（**虚线边框**，表示只是已浏览范围内的下界） |
| 7.2 | 点徽章 | 浮层列出已发现坏行，状态行写「仅在已浏览范围内」+ 显眼提示 |
| 7.3 | 点「扫描整个文件」 | 横幅走百分比进度 + 取消按钮；完成后徽章变**实线确数**（去掉 +） |
| 7.4 | 扫描中点取消 | 「已取消：坏行集合未被改动」，不报成失败 |
| 7.5 | 点某个坏行 | 列表跳转并选中该行，详情区显示真实错误 |
| 7.6 | 「全选坏行」→ 操作条「删除」 | 坏行一次清除；徽章数字随之下降 |
| 7.7 | 坏行改好（编辑成功）后 | 徽章数字同步下降 |

## 8. 字段级编辑

| # | 操作 | 预期 |
|---|---|---|
| 8.1 | 选一条记录，悬停详情树任一**标量**行 | 行尾显出小铅笔图标 |
| 8.2 | 点铅笔 | 浮层标题 = 字段路径（如 `.user.name`）；meta 显示原值与类型 |
| 8.3 | 字符串字段改成含引号/换行的文本 → 保存 | 保存成功；切到整行编辑确认转义正确（`\\"`、`\\n`） |
| 8.4 | 数字字段输入 `0x10` 保存 | 当场拒绝：「不是合法的 JSON 数字」 |
| 8.5 | 数字字段输入 `42` 保存 | 落盘的是数字 42，不是字符串 "42" |
| 8.6 | boolean 字段 | 浮层是两个按钮（true/false），点另一个直接保存 |
| 8.7 | `null` 字段 / 对象 / 数组行 | **没有**铅笔图标（有意的能力边界） |
| 8.8 | **关键**：改完后打开整行编辑对比原文 | **只有该字段的值变了** —— 键序、缩进、空格逐字节不变 |
| 8.9 | 改一个深层嵌套字段（展开 3 层后再点铅笔） | 路径正确、保存后值正确 |

## 9. 批量字段级替换

| # | 操作 | 预期 |
|---|---|---|
| 9.1 | 字段浮层勾选「同时更新其他行中此路径下值相同的字段」→ 保存 | 浮层**先关闭**，底部横幅出现二次确认（大文件会说明重写代价） |
| 9.2 | 确认前什么都不点 | 绝不发起写入（等 10 秒无动静是对的） |
| 9.3 | 点「确认替换」 | 横幅走「扫描 → 重写」连续进度；可取消 |
| 9.4 | **关键**：构造 note 里含相同文本的行，批量改 status | 只有 status 被改，note 里的相同文本**原样保留** |
| 9.5 | 结果横幅 | 报替换行数等统计（不是浮层的「已更新 X」—— 那会盖掉结果） |
| 9.6 | 批量后 Ctrl+Z | 整批一次撤销 |

|---|---|---|

## 已知边界（不是缺陷，验收时勿误报）

- `null` 字段与容器（对象/数组）**没有**字段编辑入口 —— 填值请走整行编辑。
- 单行编辑**无进度与取消**（毫秒级完成；极端大行首编辑属遗留项）。
- 历史不跨会话（关标签页即丢）；VS Code 撤销栈 label 可能与宿主光标错位（状态始终一致，只是显示）。
- 批量替换/字段级批量超 2000 行或 8MB 回退数据时**不入撤销栈**并明确告知（Ctrl+Z 那一步会失败并如实报错，历史浮层仍可回退）。
- 正则替换**刻意未做**（误操作面积不可控）。
