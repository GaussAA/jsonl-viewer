# JSONL Viewer 设计体系规范

> 本文件是插件前端（webview）的唯一设计契约。任何新增、修改功能**必须先阅读并遵循本文档**，
> 保证实现与设计不偏移、整体风格一致、可持续演进。交互原型参考：项目根目录 `prototype.html`。

---

## 0. 设计定位与原则

**气质**：现代化、卡片式、悬浮式；简约但不简陋；重点突出、有设计感。

四条铁律：

1. **主题自适应**：所有颜色使用 `--vscode-*` CSS 变量或半透明白（`rgba(255,255,255,α)`），禁止写死主题色。
2. **性能优先**：动画只动 `transform` / `opacity`（高度动画例外，见 §4.4，仅限局部子树）。
3. **一致优先**：新增功能必须复用本文档定义的令牌与组件样式，不得自造风格。
4. **克制**：动画只在"有意义"的时机出现（反馈、引导、过渡），不做装饰性循环动画。

## 1. 设计令牌（Design Tokens）

### 1.1 动效令牌

```css
:root {
  --ease-out-expo: cubic-bezier(0.16, 1, 0.3, 1); /* 快启动、优雅减速：全局唯一缓动 */
  --dur-fast: 120ms;  /* 按压 / 状态反馈 */
  --dur-base: 180ms;  /* 切换 / 弹出 */
  --dur-slow: 280ms;  /* 入场 */
}
```

> 唯一缓动 `--ease-out-expo`。浮层关闭用 `ease-in`（快速淡出）。其余一律使用 expo。

### 1.2 布局令牌

| 令牌 | 值 | 用途 |
|---|---|---|
| 左栏宽度 | `340px` | 目录列表栏 |
| 窄屏断点 | `< 700px` | 左右栏纵向堆叠 |
| 卡片圆角 | `10-12px` | 卡片、浮层 |
| 小控件圆角 | `4-7px` | 按钮、徽章、输入框 |
| 卡片间距 | `6px` | 列表条目垂直间距 |
| 内边距基准 | `14px` | 栏内容器留白 |

### 1.3 色彩令牌（均为主题自适应）

| 语义 | 规范 | 示例值（深色主题） |
|---|---|---|
| 卡片底 | `rgba(255,255,255,0.018~0.035)` | 悬浮式浮卡 |
| 边框 | `rgba(255,255,255,0.05~0.1)` | 卡片/输入/浮层 |
| 主文本 | `#d4d4d4` / `#ccc` | 标题、正文 |
| 次文本 | `#555`~`#888` | 说明、占位、行号 |

| 高亮文本 | `#88c0ff` | 选中态文字、数值 |
| 成功 | `#7fdb8a` | 复制成功、就绪点 |

## 2. 布局体系

### 2.1 整体骨架

- **左右两栏**：左栏目录列表（340px）+ 右栏详情面板，各自独立。
- **无硬分隔线**：两栏靠背景色差区分（左 `#1a1a1e` / 右 `#141418`），卡片本身就是天然分隔。
- **拖拽调节**：支持左右拖拽调节宽度；`< 700px` 自动纵向堆叠。

### 2.2 卡片化容器

页面由若干"浮卡"组成：工具栏卡片、列表条目卡片、详情大卡片、分页区、浮层面板。
卡片 = 半透明底 + 细边框 + 圆角，不依赖阴影做主要层级。

---

## 3. 组件规范

### 3.1 工具栏卡片（左上）
- 结构：图标块 + 文件名 + 状态点 / 搜索框 / 操作按钮行。
- 搜索框聚焦：蓝色描边 + `box-shadow` 光晕（`rgba(0,127,212,0.18)`）。

### 3.2 按钮（工具栏 / 浮层）
- **宽度自适应**：`flex: none; width: auto`，外框贴合文本，禁止拉伸留白。
- 状态：hover 提亮、`:active` `translateY(1px)` 按压反馈、`.active` 蓝色激活态。

### 3.3 分页条（左下，两行布局）
- 第一行：导航 `« ‹` + **窗口式页码（固定 7 槽位）** + `› »`。
- 第二行：跳页输入（数字框）+ 统计（`20/页 · N 行`）靠右。
- **窗口算法（任意页数宽度恒定）**：
  - 页数 ≤ 7 → 全显示；
  - 当前 ≤ 3 → `1 2 3 4 5 … N`；
  - 当前 ≥ N-4 → `1 … N-5 N-4 N-3 N-2 N-1 N`；
  - 其余 → `1 … p-1 p p+1 … N`。
- 跳页输入：Enter / change 生效；非法值回退原页码；spin 按钮自绘样式。

### 3.4 记录卡片（目录条目）
- 每页固定 20 条，行内只显示 `L1`/`L2` 行号标识 + 类型徽章（object/array/error）+ 单行值预览（超长省略）。
- 类型徽章配色：object 绿 / array 黄 / string 蓝 / error 红。
- 错误行：红色底 + 精简错误信息（只含原因和位置，**不回显整行原文**）。

### 3.5 JSON 树（右侧详情）
- **懒构建**：容器节点始终有块骨架，子节点首次展开才构建 DOM，收起后缓存保留。
- **数据结构**：`row`（头行）+ `block > .tree-block-inner`（子树）。
- 值渲染：key 黄、字符串绿、数字蓝、布尔紫、null 橙；超长值 `ellipsis` + title 提示。
- 折叠态标签：`▶ key: { 3 keys }` / `[ 2 items ]`；展开态 `▼ key: {`。

### 3.6 浮层面板（筛选 / 字段）
- 弹出：缩放 + 上浮；关闭：快速淡出后移除（100ms）。
- 表单：select 自绘箭头 + 深色 option；输入框聚焦蓝色描边。
- 字段列表：checkbox + 字段名 + 类型 + 置顶标记，水平排布。

## 4. 动效规范（核心）

### 4.1 动效语义总表

| 操作 | 动画 | 时长 | 说明 |
|---|---|---|---|
| 翻页（目录） | 旧卡**向左滑出** → 新卡**从右滑入** | 出 160ms / 入 280ms | 错峰 15ms×10，`pageSeq` 防连点竞态 |
| 切换记录（右栏） | 字段**逐条舒缓出现** | 行 420ms | 错峰 30ms×10；`Record #xx` 徽标轻弹 180ms |
| 展开/折叠单节点 | 子块**抽屉拉出/收回** + 箭头旋转 90° | 高 200ms / 淡 160ms / 箭头 150ms | 只动被点击行 |
| 全部展开/折叠 | 逐层**瀑布**错峰 | 层 40ms 递增 | 根 `$` 折叠时保持展开 |
| 选中卡片 | 左高亮条**生长** | 180ms | `::before` scaleY 0.4→1 |
| 复制 JSON | 按钮**确认脉冲** | 180ms | 0.8→1.15→1 + 变绿 |
| 浮层弹出/关闭 | 缩放 + 上浮 / 快速淡出 | 180ms / 100ms | |
| 按钮按压 | `translateY(1px)` | 120ms | |

### 4.2 动效触发原则

- **翻页才**播目录错峰入场；**选中只**切换高亮（原位 class 切换，不重渲染列表）。
- **切换记录才**播字段逐条出现；展开/折叠、全部展开/折叠**不**重播（先清除残留 `animating` 态）。
- 批量操作（全部展开/折叠）与单节点操作动画共存：批量走递归瀑布，单节点走单点动画。
- 同一记录重复点击：直接短路，不重渲染、不重播动画。

### 4.3 性能铁律

- 动画**只用 transform / opacity**；高度动画（抽屉）仅限单个子树、JS 测量一次。
- 过渡必须用规范模式：**先 `transition:none` 建立起始态 → reflow → 再启用过渡设目标态**（避免起始态变化触发过渡的竞态）。
- 列表/树重渲染时避免全量重播动画；用类标记（如 `.card-enter`、`.animating`）控制触发范围。
- `prefers-reduced-motion: reduce` 下全部动画关闭（时长 0.01ms）。

### 4.4 抽屉动画实现范式（可复用）

```js
function expandBlock(inner, delayMs = 0) {
  if (inner._onEnd) inner.removeEventListener('transitionend', inner._onEnd);
  inner.style.transition = 'none';
  inner.style.height = '0px';
  inner.style.opacity = '0';
  void inner.offsetWidth;
  const d = delayMs ? ` ${delayMs}ms` : '';
  inner.style.transition = `height 200ms cubic-bezier(0.16,1,0.3,1)${d}, opacity 160ms ease-out${d}`;
  inner.style.height = inner.scrollHeight + 'px';
  inner.style.opacity = '1';
  const onEnd = e => {
    if (e.propertyName !== 'height') return;
    inner.style.height = 'auto';
    inner.removeEventListener('transitionend', onEnd);
    inner._onEnd = null;
  };
  inner._onEnd = onEnd;
  inner.addEventListener('transitionend', onEnd);
}
```

## 5. 交互规范

- **hover**：卡片右移 1px + 提亮；树行淡色底；按钮提亮。
- **选中**：渐变蓝底 + 左高亮条 + 行号徽章反白。
- **复制反馈**：图标变绿 + 脉冲，1.2s 还原。
- **右键 / 键盘**：保留既有能力（复制行号/JSON、定位源码、↑↓/PageUp/PageDown/Home/End/Ctrl+C/Esc）。
- **空态**：`无记录` / `无匹配「xxx」的记录` 提示。

---

## 6. 架构与适配约束（VS Code 插件）

- **主题**：全部颜色走 `--vscode-*` 变量或半透明白；深/浅色主题均须可用。
- **RPC**：webview 与宿主的消息匹配用 `HostEndpoint` 的值（如 `'ready'`），不用键名。
- **清单**：扩展安装必须修复 `targetPlatform` 为 `win32-x64`，否则 TRAE 扫描失败。
- **目录**：分页式，每页固定 20 条。
- **错误行**：只显示精简错误（原因 + 位置），不回显整行原文。

## 7. 新增功能设计检查清单

新增或修改 UI 前逐项自检，任何一项不符即视为跑偏：

- [ ] 颜色是否全部主题自适应（`--vscode-*` 或半透明白）？
- [ ] 动画是否只用 transform/opacity（高度动画是否仅限局部子树）？
- [ ] 是否复用既有令牌（缓动、时长、圆角、间距）而非自造数值？
- [ ] 触发的时机是否符合 §4.2（不重播、不整列刷新）？
- [ ] 组件样式是否与 §3 对应组件一致（卡片、按钮、分页、浮层）？
- [ ] 是否遵循 `prefers-reduced-motion` 降级？
- [ ] 窄屏（<700px）是否正常堆叠、无水平溢出？
- [ ] 深色/浅色主题是否都验证过？
